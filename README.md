# Chesser Academy

A multi-page frontend concept for a chess training academy, built with HTML, CSS and JavaScript. It brings together an animated landing page, training services, academy information, registration, login and checkout interfaces.

## Explore locally

Clone the repository, then start a static server from its root:

```sh
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). No package installation or build step is required.

## Project map

- `index.html` — landing page and contact interface.
- `services.html` — training service presentation.
- `about.html` — academy information.
- `registration.html`, `login.html`, `checkout.html` — sample account and purchase journeys.
- `css/`, `js/`, `png/` — styling, interaction and assets.

This is a frontend portfolio concept. Account interactions use browser storage and are intended for sample data; they do not connect to a production authentication service.
